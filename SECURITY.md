# Security Policy

## Scope

This repository contains the public website and public research-process documentation for DDALKAK LAB.

## Do not report secrets publicly

If you discover a credential, API key, participant-identifying information, private correspondence, or other sensitive material in the repository, do not paste the sensitive value into a public issue.

Instead, contact the repository owner privately through an appropriate authenticated channel and identify the affected file or commit without reproducing the secret.

## Supported version

The `main` branch and current production deployment are the supported version.

## Research-data boundary

The public repository is not an approved storage location for:

- participant-level identifiable data,
- consent documents,
- passwords or access tokens,
- restricted or licensed raw datasets,
- unpublished private correspondence.

See `docs/data-management-plan.md` for the default data classification and release rules.
